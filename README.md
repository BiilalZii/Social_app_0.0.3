# تطبيق إدارة الخدمات الاجتماعية للموظفين (نسخة محسّنة)

## المميزات الجديدة

- **بحث شامل** في الموظفين والقروض والمنح
- **إدارة الميزانية** المحددة مسبقاً مع نسبة الاستهلاك
- **تقارير مفصلة قابلة للطباعة**:
  - تقرير ملخص شامل
  - تقرير المنح (مع فلترة)
  - تقرير القروض (مع فلترة)
  - تقرير فردي لكل موظف
- إحصائيات ومجموعات في لوحة التحكم
- قيم افتراضية للمنح (قابلة للتعديل)
- واجهة عربية محسّنة ومتجاوبة

## التشغيل المحلي

```bash
pip install -r requirements.txt
python app.py
```

## النشر على Render

- Build: `pip install -r requirements.txt`
- Start: `gunicorn app:app --bind 0.0.0.0:$PORT`
